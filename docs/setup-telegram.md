# Telegram

## 1. Создать бота

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Скопируйте токен в `.env`:

```
TELEGRAM_BOT_TOKEN=123456789:AAH...
```

3. Там же полезно выключить приватность групп, если планируете общий чат:
   `/setprivacy` → `Disable`. Для семейного архива обычно достаточно
   личных чатов с ботом — **и только в личных чатах бот может удалять входящие
   сообщения**, поэтому это рекомендуемый режим.

## 2. Стать администратором

Придумайте `FOTOHU_BOOTSTRAP_TOKEN` в `.env`, запустите бота и отправьте ему:

```
/start ВАШ_BOOTSTRAP_TOKEN
```

Первый, кто это сделает, становится администратором. После этого токен перестаёт
действовать — повторно им воспользоваться нельзя.

## 3. Long polling или webhook

По умолчанию — **long polling**: публичный адрес не нужен, работает за NAT.

Webhook имеет смысл, если публичный HTTPS уже есть (например, вы всё равно
поднимаете Viber):

```
TELEGRAM_USE_WEBHOOK=true
TELEGRAM_WEBHOOK_SECRET=любая-длинная-строка
FOTOHU_PUBLIC_URL=https://photos.example.com
```

Секрет проверяется по заголовку `X-Telegram-Bot-Api-Secret-Token` — без него
кто угодно, зная URL, мог бы слать боту поддельные апдейты.

## 4. Файлы больше 20 МБ

Публичный Bot API не отдаёт боту файлы крупнее 20 МБ. Свой сервер снимает это
ограничение до 2 ГБ:

1. Получите `api_id` и `api_hash` на <https://my.telegram.org/apps>.
2. Впишите их в `.env`.
3. Раскомментируйте:

```
TELEGRAM_API_BASE=http://telegram-bot-api:8081
TELEGRAM_API_LOCAL_MODE=true
```

4. Запустите с профилем:

```bash
docker compose --profile local-api up -d
```

`TELEGRAM_API_LOCAL_MODE=true` включает важную оптимизацию: сервер отдаёт путь к
файлу на диске, том общий с ботом, и повторное скачивание по HTTP не требуется.

## 5. Как присылать без сжатия

Это главное для качества — бот подскажет по команде `/howto`:

- **Android:** скрепка → Галерея → выбрать → ⋮ → «Отправить без сжатия»
- **iPhone:** скрепка → Файл → «Фото»; либо долгое нажатие на «Отправить»
- **Desktop:** перетащить в окно и снять галочку «Сжать изображение»

Отправленное обычным фото Telegram пережимает у себя на сервере — восстановить
оригинал невозможно, см. [limitations.md](limitations.md).
