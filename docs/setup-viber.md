# Viber

> ⚠️ Viber **не умеет удалять сообщения ботом** — в его API нет такого метода.
> Очистка переписки работает только в Telegram, см. [limitations.md](limitations.md).

## 1. Создать бота

1. Зайдите на <https://partners.viber.com> и создайте бота.
2. Скопируйте токен в `.env`:

```
VIBER_BOT_TOKEN=4453b6ac1s345678-e02c9d3a9c1b-a1b2c3d4e5f6
VIBER_BOT_NAME=FotoHu
```

## 2. Публичный HTTPS обязателен

Viber работает **только** через вебхук на публичном HTTPS с сертификатом от
настоящего центра сертификации. Самоподписанный он не примет.

Профиль `tls` поднимает Caddy, который выпустит сертификат автоматически:

```
FOTOHU_PUBLIC_URL=https://photos.example.com
FOTOHU_DOMAIN=photos.example.com
```

```bash
docker compose --profile tls up -d
```

Домен должен указывать A-записью на этот сервер, порты 80 и 443 — открыты.
Вебхук регистрируется автоматически при старте; в логе появится
`viber: webhook at https://.../webhook/viber`.

## 3. Подпись запросов

Каждая доставка от Viber подписана заголовком `X-Viber-Content-Signature`
(HMAC-SHA256 тела по токену бота). FotoHu проверяет её и отвечает `403` на всё
неподписанное — без этого любой, кто узнал URL, слал бы события от имени Viber.

## 4. Как присылать без сжатия

Скрепка → **«Файл»** (не «Галерея») → выбрать снимок.

Отправленное через «Галерею» Viber пережимает у себя на сервере — по умолчанию
бот такие снимки отклоняет с подсказкой.

## Команды

Viber не даёт ботам удобных inline-кнопок, поэтому админка здесь текстовая —
операции те же, что в Telegram:

| | |
|---|---|
| `/join КОД` | вход по приглашению |
| `/me`, `/last`, `/howto`, `/help` | как в Telegram |
| `/status` | очередь, объём, ошибки |
| `/members` | участники |
| `/invite [admin]` | код приглашения |
| `/groups [название]` | список групп или создание |
| `/storage`, `/folders` | хранилище и раскладка |
| `/mode per_person\|shared\|per_group` | режим раскладки |
| `/purge [часы]` | настройка очистки |

Полное меню с кнопками остаётся в Telegram (`/admin`).
