# Google Drive

## 1. Создать OAuth-клиент

1. <https://console.cloud.google.com> → создайте проект.
2. **APIs & Services** → **Library** → включите **Google Drive API**.
3. **OAuth consent screen** → тип **External** → заполните обязательные поля.
   Пока приложение в статусе *Testing*, добавьте всех, кто будет подключать
   аккаунт, в **Test users** — иначе Google не пустит.
4. **Credentials** → **Create credentials** → **OAuth client ID** →
   тип **Web application**.
5. **Authorized redirect URIs:**

```
https://ваш-домен/oauth/callback
```

6. Client ID и client secret → в `.env`:

```
GDRIVE_CLIENT_ID=...apps.googleusercontent.com
GDRIVE_CLIENT_SECRET=GOCSPX-...
```

## 2. Об области доступа

По умолчанию запрашивается **`drive.file`** — приложение видит только те файлы,
которые создало само. Ваши остальные документы и фото боту недоступны в принципе.
Для семейного архива этого достаточно: бот сам создаёт корневую папку и работает
внутри неё.

Ограничение обратной стороны: указать боту **уже существующую** чужую папку с
таким доступом нельзя — Google её просто не покажет. Если это нужно, потребуется
полный scope `drive`; он включается флагом `full_access` у storage-аккаунта и
означает доступ ко всему Диску. Для большинства семей это лишнее.

## 3. Подключить

`/admin` → **☁️ Хранилище** → **＋ Подключить облако** → **Google Drive** →
**🔗 Подключить аккаунт**.

Если Google покажет «Google hasn't verified this app» — это ожидаемо для
приложения в статусе Testing: **Advanced** → **Go to … (unsafe)**.

## Как это работает

- Google Drive адресует папки по **id, а не по пути**, поэтому FotoHu держит
  таблицу `folder_cache` (путь → id). После первого прохода дерево папок
  разрешается без единого запроса к API.
- Файлы до 5 МБ уходят multipart-запросом, крупнее — resumable-сессией кусками
  по 10 МБ (Drive требует кратности 256 КиБ).
- Если Drive принял лишь часть куска, он сообщает точное смещение в заголовке
  `Range`, и отправка продолжается ровно оттуда.

## Проверка целостности

Drive возвращает `md5Checksum`, который сверяется с посчитанным при скачивании —
побайтная проверка работает.
