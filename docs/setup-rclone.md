# Box, Dropbox, pCloud, Яндекс.Диск и ещё ~70 облаков — через rclone

Родные адаптеры есть для OneDrive и Google Drive. Всё остальное подключается
через [rclone](https://rclone.org), который умеет больше семидесяти провайдеров:
Box, Dropbox, pCloud, Яндекс.Диск, Mega, Koofr, WebDAV, Nextcloud, S3, Backblaze
B2, SFTP и так далее.

## 1. Настроить remote

rclone уже установлен в образе. Настройка интерактивная:

```bash
docker compose run --rm bot rclone --config /data/rclone.conf config
```

Дальше по подсказкам: `n` (new remote) → имя, например `box` → выбрать
провайдера → авторизоваться.

> Если сервер без браузера, rclone предложит вариант «headless»: он даст команду
> вида `rclone authorize "box"`, которую нужно выполнить на своём компьютере
> (там, где есть браузер), и вставить полученный токен обратно.

Проверить:

```bash
docker compose run --rm bot rclone --config /data/rclone.conf lsd box:
```

## 2. Подключить в боте

`/admin` → **☁️ Хранилище** → **＋ Подключить облако** →
**Другое облако (через rclone)** → ввести имя remote.

Принимается и голое имя (`box`), и имя с подпапкой (`box:Семейный архив`).

Бот сразу проверит связь и покажет результат.

## 3. Локальный конфиг (без Docker)

```
RCLONE_BINARY=rclone
RCLONE_CONFIG=/home/you/.config/rclone/rclone.conf
```

## Особенности

- rclone сам делает чанкованную загрузку с повторами, поэтому FotoHu просто
  вызывает `rclone copyto` и затем перечитывает файл, чтобы получить его размер
  и хеш.
- Код возврата rclone `5` («temporary error») трактуется как повод повторить
  попытку позже; остальные ненулевые коды — как настоящая ошибка.
- Свободное место показывается, если remote поддерживает `rclone about`;
  многие провайдеры этого не умеют — тогда квота просто не отображается.
- Проверка хеша работает, если remote отдаёт SHA-256, SHA-1 или MD5
  (`rclone lsjson --hash`). Иначе сверяется размер.
